# MarkStudio 使用说明

MarkStudio 是一款所见即所得的 Markdown 桌面编辑器，基于 Electron 31 与 Vditor 构建，支持 **Windows 10 / 11（x64）**、**macOS（Intel / Apple Silicon）** 与 **Linux x64**。

---

## 一、文件说明


| 平台    | 文件                                              | 说明                                                                |
| ------- | ------------------------------------------------- | ------------------------------------------------------------------- |
| Windows | `MarkStudio-Setup-1.0.0.exe`                      | **安装版**（推荐）。双击安装，桌面/开始菜单生成快捷方式，支持卸载。 |
| Windows | `MarkStudio-Portable-1.0.0.exe`                   | **便携版**。免安装，解压或直接双击即可运行，适合 U 盘携带。         |
| macOS   | `MarkStudio-1.0.0-mac-x64.dmg` / `-mac-arm64.dmg` | **磁盘映像**。拖入「应用程序」文件夹即完成安装。                    |
| Linux   | `MarkStudio-1.0.0-linux-x64.AppImage`             | **便携版**。赋予执行权限后直接运行。                                |
| Linux   | `MarkStudio-1.0.0-linux-x64.deb`                  | **Debian/Ubuntu 安装包**。`sudo dpkg -i` 安装。                     |

## 二、安装

### Windows

1. 双击 `MarkStudio-Setup-1.0.0.exe`。
2. 如 Windows 弹出 SmartScreen 提示，点「更多信息」→「仍要运行」。
3. 在向导中点「下一步」→「安装」→「完成」。安装目录默认为当前用户的 `AppData\Local\Programs\MarkStudio`，可以修改。
4. 安装完成后即可从桌面快捷方式或开始菜单启动 MarkStudio。

> 便携版无需安装，双击 exe 直接运行即可；首次启动速度会稍慢属正常现象。

### macOS

1. 双击 DMG 文件，将 **MarkStudio** 图标拖入「应用程序」文件夹。
2. 首次启动时若提示「无法打开」（未签名/未公证构建）：在「应用程序」中**右键 → 打开**，或在「系统设置 → 隐私与安全性」中点「仍要打开」。
3. 安装后可在启动台（Launchpad）中启动 MarkStudio。

### Linux

- **AppImage**：`chmod +x MarkStudio-*.AppImage && ./MarkStudio-*.AppImage`（建议移动到 `~/Applications/` 并创建桌面快捷方式）。
- **deb**：`sudo dpkg -i MarkStudio-*.deb`（出现依赖错误时执行 `sudo apt install -f` 后重试）。

## 三、卸载

### Windows

**方式一（推荐）：** 打开 Windows「设置」→「应用」→「安装的应用」，搜索 **MarkStudio**，点右侧「卸载」。

**方式二：** 进入安装目录（默认 `C:\Users\<你的用户名>\AppData\Local\Programs\MarkStudio`），双击运行 `Uninstall MarkStudio.exe`，按向导完成即可。

> 卸载会删除程序本体；你的 Markdown 文档和软件设置（`%APPDATA%\markstudio`）不受影响，如需彻底清理可手动删除该目录。
> 便携版无卸载程序，直接删除 exe（或解压目录）即可。

### macOS

在「应用程序」文件夹中把 **MarkStudio** 拖入废纸篓即可。设置数据在 `~/Library/Application Support/markstudio`，如需彻底清理可一并删除。

### Linux

- **deb**：`sudo apt remove markstudio`（或「设置 → 应用」中卸载）。
- **AppImage**：直接删除 AppImage 文件。
- 设置数据在 `~/.config/markstudio`，如需彻底清理可一并删除。

## 四、快速上手

启动后进入欢迎页：

- **新建文档**：开始写一篇新文章（未保存前标题为「未命名」，Ctrl+S 时选择保存位置）。
- **打开文件...**：选择任意 `.md` / `.markdown` / `.txt` 文件。
- **打开文件夹...**：把一个目录作为工作区，左侧显示**完整文件树**（所有文件夹和文件都带名称与图标：📁 文件夹、📄 可编辑的 Markdown、📎 其它文件）。点击 Markdown 在编辑器打开，点击其它文件用系统默认程序打开。
- 最近打开的文件列在下方，点击直达；也可以把 `.md` 文件直接**拖进窗口**打开。

进入编辑界面后，**顶部菜单栏常驻显示**，共 7 个菜单：

`文件(F)` · `编辑(E)` · `段落(D)` · `格式(G)` · `视图(S)` · `主题(T)` · `帮助(H)`

每个菜单标题带**英文括号助记符**（文字与括号紧凑排列）：按住 `Alt` 再按对应字母即可打开菜单，例如 `Alt+F` 打开「文件」、`Alt+G` 打开「格式」。**菜单激活模型**：首次需要**点击**某个菜单激活菜单栏；激活后鼠标**悬停即开**、菜单间毫秒级切换（点「格式」再滑到「视图」时旧菜单瞬间关闭、新菜单同时展开）；点击已打开的菜单或按 Esc 关闭后，再次回到「需先点击」的状态。键盘方向键 / Enter / Esc 全程可操作。

保存、另存为在「文件」菜单下拉中（导出 PDF/HTML 也在其中）；**「文件 → 设置」子菜单是通用设置入口**：「正文字体（整篇）」一键切换整篇字体（宋体/楷体/微软雅黑/黑体/仿宋/等线/Consolas/系统默认）或进入完整设置（Ctrl+,）；查找/替换在「编辑」菜单（Ctrl+F）；标题 1~6、列表、代码块、**表格（含行列增删移动）**等排版操作在「段落」菜单；加粗/斜体/删除线、**选中文本的字体/字号/颜色**在「格式」菜单。

**编辑区底部居中悬浮着一条格式工具栏**（浮动条，非全宽横栏）。它默认停靠在窗口**最底部居中**位置，**背景透明不遮挡正文文字**，鼠标靠近时变为「手」形光标——你可以**按住工具栏空白处上下拖动**，把它固定在窗口内你喜欢的高度，位置会自动记忆、下次启动仍在原处。工具栏收拢了最常用的操作，每个按钮都有对应菜单项和快捷键：

- `列表▾`：下拉选择 无序列表 / 有序列表 / 任务列表
- `B` `I` `</>`：加粗 / 斜体 / 行内代码
- `🔗`：插入链接（Ctrl+K）
- `🖼`：插入图片（可直接粘贴截图）
- `❝`：引用
- `1▾`：下拉选择 标题 1 ~ 标题 6
- `⋯`：更多操作——代码块、插入表格、删除线、分隔线、撤销、重做、查找
- `</>&nbsp;源码`（最右侧）：切换**源代码模式**（Ctrl+/）

> **正文与工具栏实时联动**：把光标点到正文的某处，工具栏会自动高亮对应当前格式的按钮——光标在加粗文字里时 `B` 点亮，在列表里时 `列表` 点亮，在标题里时 `1▾` 点亮并显示具体级别，在引用/链接/行内代码中同理。这样一眼就能看出光标当前所处的格式。
>
> 工具栏按钮点击时会自动把焦点还给正文，因此「加粗」等命令始终作用在当前光标处，不会出现点了没反应的情况。

### 无框标题栏 + 多标签

窗口采用**无边框设计**，标题栏由应用自绘，从左到右依次为：

- **MarkStudio 固定标签**（软件 LOGO + 名称，浅灰选中态，始终高亮）——**点击它弹出系统菜单**：移动 / 最小化 / 最大化（还原）/ 关闭；双击标题栏空白处可切换最大化；
- **文件标签行**：每个打开的文件一个标签（文件图标 + 文件名 + 关闭按钮 ✕ + 未保存橙点），紧跟其后是**「＋」新建标签**按钮（等价 Ctrl+N）；
- **窗口按钮**（最小化 / 最大化(还原) / 关闭，关闭悬停变红）。
- 点击标签即切换，编辑区立即显示对应文件内容，各标签的编辑内容、光标位置、滚动位置互不干扰；
- **标签可拖动重排**：按住任意文件标签左右拖动，出现蓝色插入线提示落点，松手完成换位；
- 「文件 → 最近文件」「欢迎页最近列表」「拖入文件」打开的文件都**在当前窗口的标签中打开**，不会弹出新窗口；
- 关闭最后一个标签回到欢迎页；Ctrl+Shift+N 仍可用**多窗口**同时编辑。
- **标签「✕」悬浮卡片**：把鼠标移到某个文件标签的关闭按钮「✕」上，会在下方弹出悬浮卡片，显示 **a. 文件名**（输入框，可直接**编辑重命名**，Enter 确认、Esc 取消，重命名同步落盘并更新最近文件记录）和 **b. 该文件的完整路径**；未保存到磁盘的新文件卡片中会显示「尚未保存到磁盘（保存后即可重命名文件）」；鼠标移开自动收起。

### 表格编辑（正文内增删行列、移动行列、行列拉伸、按行/列选择）

在正文的表格里把光标点到任意单元格，再点工具栏 `⊞`（或 Ctrl+Shift+T），会弹出**表格操作面板**，可对该表格：

- **行操作**：上方插入行 / 下方插入行 / 删除当前行 / 行上移 / 行下移
- **列操作**：左侧插入列 / 右侧插入列 / 删除当前列 / 列左移 / 列右移
- **单元格对齐**：左对齐 / 居中 / 右对齐（图标按钮，作用于**整个表格**的全部单元格，保存为 Markdown 对齐标记）
- **删除整个表格**

**行/列快捷选择（类似常用文字处理软件）**：

- **按行选择**：鼠标移到**表格最左侧的竖向细条**上，经过某一行时光标变为箭头形，**左键单击即选中该行全部单元格**；按住上下拖动可连续选中多行；
- **按列选择**：鼠标移到**表格上方的横向小方格条**上，左键单击选中整列，按住左右拖动可连续选中多列；
- 选中行/列/单元格区域后**右键**，弹出**表格操作菜单**：对齐（左对齐 / 居中 / 右对齐，作用于选区）、行上移 / 行下移、列左移 / 列右移、删除整个表格（增删行列在表格工具条上，右键菜单不再重复列出）——操作作用于当前选中的行/列区域；
- **拉伸行高**：鼠标移到两行之间的横线上（或表格最底部），上下拖动即可改变行高——拖动某行的**上边框**改变的是**上一行**的高度（与常用文字处理软件一致）；
- **拉伸列宽**：鼠标移到两列之间的竖线上，左右拖动即可改变列宽；
- **拉伸表格外边框**：表格**最左边**和**最右边**的边框也可以拖动——拖左边框移动表格左缘（右缘不动、左边距随之变化），拖右边框移动表格右缘（左缘不动），与常用文字处理软件调整表宽的操作一致；拖出的表宽会记住，重新打开文档自动恢复。

光标不在表格内时，`⊞` 则显示「行数 × 列数」选择网格用于插入新表格（支持**自定义输入行数 × 列数**）。同样的全部操作也可以在**「段落 → 表格」子菜单**里点选（插入表格… / 上方插入行 / 下方插入行 / 删除行 / 行上移 / 行下移 / 左侧插入列 / 右侧插入列 / 删除列 / 列左移 / 列右移 / 删除整个表格），不依赖工具栏。**正文中右键**任意位置也会弹出表格操作右键菜单（对齐 / 行列移动 / 删除表格，光标在表格内时可用）；**选中整个表格后右键**会出现「删除选中的表格」。

### 行号

正文左侧显示**行号栏**，背景为**左浅右白的柔和渐隐**，与正文之间没有任何生硬的分割线；行号**紧贴正文左缘**（跟随正文的居中位置自动对齐），且**每个数字都与对应段落的首行文字垂直居中对齐**。行号随内容编辑自动重排、随滚动同步；源代码模式下则按物理行号显示。行号可以随时开关：**「视图」菜单 → 行号**（带勾选标记）。行号栏还有两个快捷操作：

- **右键**行号栏：弹出菜单「隐藏行号」，一键关掉行号；
- **左键点击**某个行号：**选中该行对应的整行文字内容**（即时渲染模式按块、源代码模式按物理行）。

左侧栏可切换「文件 / 大纲」两个面板（Ctrl+\ 显示/隐藏）。**侧边栏宽度可自由调整**：鼠标移到侧栏右缘的分隔条上（悬停时高亮）按住左右拖动即可，宽度自动记忆。文件/文件夹名称过长放不下时，列表底部会出现**横向滚动条**，可左右滑动查看完整名称。「文件」面板按**层级缩进**展示完整的文件夹/文件树，目录结构一目了然。**打开任意文件时，「文件」面板会自动定位到该文件所在的文件夹并高亮当前文件**——无需手动「打开文件夹」，文件列表始终对应当前文档的位置。大纲根据文档标题自动生成，**点击任意标题，正文立即跳转到对应位置（无过渡动画）**。

## 五、主要功能

- **所见即所得即时渲染**：输入 `# 标题` 立即变成大号标题，写作过程不暴露 Markdown 符号（点顶部「源代码」可切回纯源码视图）。
- **完整排版支持**：多级标题、加粗/斜体/删除线、有序/无序/任务列表、引用、代码块（语法高亮）、行内代码、表格（支持正文内增删行列、移动行列）、分隔线、链接、图片（可直接粘贴截图插入）。
- **行号显示**：正文左侧行号栏，编辑自动重排、滚动同步；源代码模式按物理行显示。
- **正文字体可自定义（字体名本地化显示）**：在**「文件 → 设置」**子菜单（或 Ctrl+, 完整设置）中可选择**正文字体**（列出系统已安装的全部字体，**中文字体以中文显示**，如微软雅黑、宋体、楷体、等线；英文字体以英文显示，如 Segoe UI）和**正文字号**，设置自动记忆；「文件 → 设置 → 正文字体（整篇）」子菜单还能一键切换常用字体（宋体/楷体/微软雅黑/黑体/仿宋/等线/Consolas/系统默认）。中文系统下正文默认以**微软雅黑**渲染，悬浮栏字体框也如实显示「微软雅黑」。
- **Ctrl + 滚轮缩放字体**：在正文上按住 `Ctrl` 滚动鼠标滚轮即可逐级放大/缩小正文字体（与「视图」菜单的放大/缩小等价，连续滚动连续缩放），字号自动记忆。
- **选中文本单独设置字体/字号/颜色**：选中任意文字（支持跨段落、跨行），在「**格式**」菜单里单独设置，**只影响选中的这段文字，不影响其他内容**：
  - 「格式 → 字体」：常用字体（宋体/黑体/楷体/仿宋/微软雅黑/等线/Consolas）+「**所有系统字体…**」打开字体面板——列出**系统已安装的全部字体**，每个都以自己的字体渲染「Aa 甲」样例，顶部搜索框即时过滤；
  - 「格式 → 字号」：10~64 常用字号 +「自定义字号…」输入任意值（8~120）；
  - 「格式 → 颜色」：16 色色板（黑白灰 + 红橙黄绿青蓝紫粉）+「自定义颜色…」系统取色器 +「取消颜色」；
  - 已设样式的文字再次设置会**合并**属性（如先设楷体再设 24 号，两者都保留）；只选其中一部分文字设置时形成**嵌套样式**；「格式 → 清除所选文字样式」一键还原为正文默认（只去样式、不删文字）。
  - 样式保存在 Markdown 源码里（`<span style>` 标记），**随文件保存、任何设备打开都还原**；源代码模式下同样支持选中设置。
- **段落行距自定义**：「**视图 → 段落行距**」提供 1.4 紧凑 / 1.6 稍紧凑 / 1.75 默认 / 1.9 适中 / 2.1 宽松 / 2.4 很宽松 六档（当前档带勾），另有「自定义行距（设置…）」在设置里输入任意值（1.0~3.0）。段落之间的间距随设置即时变化并自动记忆。
- **标题分隔线美化**：正文标题下不再是一条生硬的灰色实线——**h1 不再画线**，**h2 保留一条向右渐隐的细线**，视觉更轻盈。
- **大纲「标签」图标 + 大号折叠箭头**：大纲每项标题前按级别显示**彩色标签图标**（h1~h6 六种颜色），一眼区分层级；折叠/展开**箭头加大**，更好点按。
- **工具栏与正文联动**：光标落在正文的加粗/斜体/链接/引用/标题/列表/行内代码中时，悬浮工具栏对应按钮自动点亮，随时可知光标当前格式。
- **外部修改直接保存**：文档被外部程序修改后，如果你这边有未保存的改动，保存时**不再弹「重新加载」确认框**——直接保存覆盖（状态栏提示「磁盘版本已变化：保存时将直接覆盖」）；若你这边没有改动，则自动载入磁盘最新版本。
- **大文件优化**：打开超大文档（>150KB）时自动关闭代码语法高亮并显示「加载中」提示；>400KB 的文档启用**屏外内容懒渲染**（content-visibility），显著降低大文件滚动和打开时的布局开销；字数统计改为防抖计算，打字更顺滑。
- **公式**：支持 KaTeX 数学公式（行内 `$...$` 与块级 `$$...$$`）。
- **查找/替换**：Ctrl+F 打开，支持上/下定位、替换、全部替换、区分大小写。
- **双主题（参考 Visual Studio Code 配色）**：「主题」菜单中切换**浅色**（白底，对应 VS Code Light+）/ **深色**（黑底，对应 VS Code Dark+）界面，设置自动记忆，**切换即时生效、不重建文档**——即使打开超大文件，切换主题也是瞬间完成、不卡顿、不丢失光标；另有 4 种内容主题——跟随界面（推荐）、浅色（GitHub 风格）、Ant Design、公众号风格。
- **打字机模式 / 专注模式**：打字机模式让光标所在行保持居中；专注模式淡化其他内容，突出当前段落。
- **自动保存 / 个性化**：在**「文件 → 设置」**（Ctrl+,）中可开启自动保存、调整字号、选择正文字体、打字机模式、专注模式等。
- **导出**：文件 → 导出，可导出 Word（.docx，真实 OOXML、公式可在 Word 中编辑）、PDF、HTML，或调用系统打印（Ctrl+P）。
- **多窗口**：Ctrl+Shift+N 新建窗口，可同时编辑多个文档；已修改的文档关闭时会提示保存。
- **文件树实时刷新**：外部新增/修改的文件会同步出现在左侧文件树。
- **文件列表跟随当前文件**：打开文件时，左侧「文件」面板自动加载并定位到该文件所在的文件夹、并高亮当前文件，无需手动「打开文件夹」；切换打开不同文件夹的文件时，文件树随之自动切换。
- **侧边栏宽度可调**：鼠标按住侧栏右缘的分隔条左右拖动即可调整宽度（180–480px），松手后自动记忆，下次启动保持。
- **长文件名横向滚动**：文件/文件夹名称过长超出侧栏宽度时，列表底部出现横向滚动条，可左右滑动查看完整名称，不再被截断省略。
- **精修文件图标**：「文件」面板改用**按类型着色的 SVG 矢量图标**——文件夹为琥珀色（展开/收起两种形态）、Markdown 蓝色（M↓）、PDF 红色（PDF）、图片绿色、其他文件灰色，观感统一、一目了然，替代了旧的 emoji 图标。
- **右键菜单 + 中英互译（悬浮弹窗）**：在正文中选中文字后**右键**，弹出菜单包含**剪切 / 复制 / 粘贴 / 全选 / 翻译**。「翻译」会**自动识别选中内容的语言方向**（英文自动译为中文、中文自动译为英文），并把翻译结果以**悬浮弹窗**的形式展示在选区旁边——弹窗顶部显示方向（如「中文 → 英文」）、原文，下方为译文，**全程不替换、不改动原文正文**；点弹窗里的「复制译文」一键把译文复制到剪贴板。翻译服务由主进程调用（默认使用免 key 的 MyMemory 接口，开箱即用），网络不可用时会给出明确提示。
- **正文宽度与对齐**：正文默认**全宽、左对齐**撑满编辑区（顶格排版，不再居中窄栏）。在「视图 → 正文宽度」可切换 **全宽（推荐）/ 1200 / 1000 / 860（窄版式）** 像素宽；设置里还有「正文居中显示」开关——限宽时可选**居中**或**靠左**对齐。行号栏始终紧贴正文左缘（居中时自动跟随正文一起居中，不再悬空在窗口最左侧）。
- **自动换行开关**：「视图 → 自动换行」（或设置里）可切换。**开启**时长行自动折行；**关闭**时长行**不再折行**，编辑区**底部出现横向滚动条**，左右拖动滚动条即可查看整行内容——渲染视图与源代码视图行为一致。
- **源代码模式可进出**：点悬浮栏最右侧 `</> 源码`（或 Ctrl+/）进入源代码模式；进入后该按钮变为 `</> 退出源码`，**再次点击即可返回**即时渲染模式（不再是进了就出不来）。
- **大纲折叠 / 展开 + 标签图标**：左侧「大纲」面板为**层级树**，每个条目前按标题级别显示**彩色标签图标**（h1~h6 六种颜色），带子标题的条目还有**加大的箭头（▾/▸）**，点击可**折叠/展开**其子标题，状态在会话内保持；叶子标题无箭头。点击任意标题仍为正文跳转。
- **状态栏实时行:列**：状态栏（底部右侧）实时显示**保存状态 / 光标所在的「行:列」/ 字数 / 字符数**，信息靠右紧凑排列；同时**当前行对应的行号高亮**，便于定位。文件完整路径不再占用状态栏——把鼠标悬浮到标题栏文件标签的「✕」上，悬浮卡片中即可查看。
- **悬浮栏图标与交互优化**：悬浮工具栏按钮全部换成**统一风格的 SVG 矢量图标**（加粗、斜体、行内代码、引用、链接、图片、标题、源码等），鼠标**悬停即时高亮**——按钮轻微上浮、图标放大、对比增强，带平滑过渡，操作反馈丝滑（不再只有点击才有反应）。
- **行号栏美化**：行号改用更细的等宽数字（tabular-nums），字号收紧、右对齐，**当前行行号以主题色加粗高亮**，整体更干净。
- **正文字体快捷切换**：除「文件 → 设置」外，「**文件 → 设置 → 正文字体（整篇）**」子菜单可直接一键切换常用字体——**系统默认 / 宋体 / 楷体 / 微软雅黑 / 黑体 / 仿宋 / 等线 / Consolas**，选中项带勾，即时生效并记忆。
- **动态菜单**：「视图」菜单的按钮文字会随状态自动变化——侧栏打开时显示「隐藏侧边栏」，点击后变为「打开侧边栏」；「源代码模式」进入后变为「退出源代码模式」，「行号」带勾选标记，随时反映当前状态。

## 七、常见问题

**问：双击 .md 文件打不开 / 想用 MarkStudio 打开文件？**
在 MarkStudio 内「文件 → 打开...」；或把文件拖进窗口。若已安装，右键 .md 文件 →「打开方式」→ 选择 MarkStudio 也可以关联。

**问：保存后在哪里找到文件？**
把鼠标悬浮到标题栏文件标签上的「✕」，弹出的悬浮卡片会显示该文件的**完整路径**；「文件 → 打开所在文件夹」可直接在资源管理器中定位。

**问：杀毒软件提示可疑？**
Electron 打包程序偶尔会被误报。本程序由本机构建，**除你主动使用「翻译」功能外不发起任何外部网络请求**（文档内容、设置与最近文件记录全部只保存在本机），如被拦截请将安装目录加入信任/白名单。

**问：界面文字大小不合适？**
视图菜单「放大字体 / 缩小字体」（Ctrl+= / Ctrl+-），或在「文件 → 设置...」中调整。
